## 数据来源

### 股票行情
- **工具**：[AKShare](https://akshare.akfamily.xyz/) `ak.stock_zh_a_hist()`
- **复权方式**：后复权（hfq）
- **频率**：日度
- **时间范围**：2020-01-01 至 2026-05-23
- **字段**：日期、开盘价、收盘价、最高价、最低价、成交量、成交额
- **备注**：创业板（300510）和深市（000988）采用腾讯源 `ak.stock_zh_a_daily()` 作为备用接口

### 市场指数
- **沪深 300（000300）**：作为 CAPM 分析的市场基准，来源：AKShare `ak.stock_zh_index_hist_csindex()`
- **中证 500（000905）**：自选指数，代表中小盘市场表现，便于与沪深 300 大盘对比，来源同上
- **选择理由**：中证 500 涵盖 500 只中小市值股票，与本组所选中小盘标的（晨丰科技、金冠股份等）相关性更高，有助于更全面评估本组股票相对大盘与中小盘的表现

### 宏观指标

| 指标 | 来源 | 选择理由 |
|------|------|----------|
| CPI 同比增速 | AKShare `ak.macro_china_cpi_yearly()` | 必选项；CPI 反映通胀压力，直接影响货币政策和市场流动性 |
| 人民币/美元汇率（月均中间价） | AKShare `ak.currency_boc_safe()` | 汇率影响出口企业利润及外资持仓偏好，本组军工、电子等行业对汇率较敏感 |

### 财务数据
- **工具**：AKShare `ak.stock_financial_analysis_indicator()`
- **指标**：净资产收益率（ROE）、净利润率、资产负债率、营业收入增速
- **时间范围**：近 5 个年度（2020–2024）
- **格式**：长格式（Long format），字段：`code, name, year, indicator, value`
- **文件**：`data/finance/finance_ratios.csv`

## 存储方式

### 基础方式：CSV（方式 A）

所有原始数据和清洗后数据均以 **CSV 格式**存储，位于 `data/` 各子目录下。

**CSV 的优点：**
1. 人类可读，可直接用文本编辑器或 Excel 打开
2. 通用性极强，所有编程语言和工具均支持
3. 无需特殊解码库，零依赖读取
4. 适合小到中等规模数据集（本项目每个文件 < 2 MB）

**CSV 力不从心的场景：**
- 数据量超过几百万行时，读写速度慢、内存占用大
- 无法存储数据类型信息（所有列读入后需手动转换类型）
- 不支持压缩存储和列式读取，随机访问效率低
- 不适合嵌套/层级结构数据

### 进阶方式：Parquet（方式 B）

在 `02_clean.ipynb` 中，清洗后的数据额外保存一份 Parquet 格式，与 CSV 并存于 `data/clean/`：
- `data/clean/stock_clean.csv`（方式 A）
- `data/clean/stock_clean.parquet`（方式 B）

**选择 Parquet 的理由：**
1. **列式存储**：只需读取分析所需的列（如仅读取 `date, code, close`），避免加载无关数据
2. **自带 Schema**：数据类型信息持久化，`datetime` 等类型读入后无需手动转换
3. **压缩效率高**：同等数据量下体积通常比 CSV 小 3–5 倍
4. **与 pandas/PyArrow 原生集成**：适合大规模金融数据分析流水线

## 如何运行

1. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

2. **下载原始数据**
   运行 `01_download.ipynb`（所有数据已预下载，可跳过直接进入清洗步骤）

3. **清洗与存储**
   运行 `02_clean.ipynb`，生成 `data/clean/` 下的清洗数据（CSV + Parquet）及 `data/combined/combined_data.csv`

4. **描述统计与回归分析**
   运行 `03_analysis.ipynb`，生成所有图表（保存至 `output/`）及回归结果

5. **阅读完整报告**
   打开 `report.html`，无需运行代码即可查看完整分析流程与结论
